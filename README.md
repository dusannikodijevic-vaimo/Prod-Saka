# Prod-Saka
Prod-Saka is a project designed to automate critical workflow of Saka (PLP, PDP, Search). It leverages tools like Playwright to ensure robust testing and efficient CI/CD pipelines.

## Features
- [Feature 1: Automated browser testing with Playwright. Around 40 test, desktop only for now.] 
- [Feature 2: Slack notifications for test results]
- [Feature 3: GitHub Actions for CI/CD]
